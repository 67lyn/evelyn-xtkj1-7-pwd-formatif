Website Portofolio

Ini adalah proyek website saya yang menggunakan HTML dan CSS.

Halo! Saya adalah seorang siswi yang memiliki ketertarikan besar terhadap dunia teknologi. Saya sedang mempelajari hal-hal baru, terutama yang berhubungan dengan komputer, jaringan, programming, dan lainnya. Menurut saya, teknologi adalah sesuatu yang menarik karena dapat membantu manusia di era ini.

Sekarang, saya sedang pelajari dasar-dasar pemogramman, khususnya HTML dan CSS. Saya mulai belajar bagaimana membuat struktur sebuah website, mengatur tampilannya, serta memahami fungsi setiap elemen yang digunakan. Walaupun saya masih di dalam tahap belajar, saya mau terus mengembangkan kemampuan saya agar suatu hari bisa membuat website sendiri.

Selain web development, saya juga penasaran dengan bidang jaringan komputer. Saya ingin lebih memahami bagaimana perangkat dapat saling terhubung, bagaimana internet bekerja, serta bagaimana cara membangun dan mengelola sesuatu yang baru.

Saya juga memiliki penasaran banget terhadap bidang Web Developerx. Saya tertarik mempelajari bagaimana programmer yang bertugas bisa membangun, memelihara, dan mengembangkan aplikasi atau situs web. Saya ingin memahami cara membangun web yang aman, mengatasi masalah yang muncul, serta memastikan bahwa pengguna dapat menggunakan web dengan lancar dan bertanggung jawab.

Dalam proses belajar, saya nyadar bahwa memahami teknologi membutuhkan banyak waktu, latihan, dan kesabaran. Biasa saya menemukan kesulitan ketika mempelajari sesuatu yang baru, tetapi saya berusaha untukmencari informasi dan mencoba secara langsung. Saya percaya setiap kesalahan adalah bagian dari proses kita untuk menjadi lebih baik.

Di luar kegiatan belajar, saya juga senang mengeksplorasi berbagai hal yang berkaitan dengan game, musik, dan forografi. Saya mencoba mengambil kesempatan untuk mencoba sesuatu yang belum pernah di lakukan. Dari pengalaman-pengalaman tersebut, itu dapat membantu saya menemukan motivasi untuk terus berkembang.

Untuk ke depannya, saya berharap dapat menjadi seseorang yang memiliki pengetahuan luas tentang teknologi. Saya ingin terus belajar dan meningkatkan kemampuan saya dalam membuat website. Dengan konsistensi, kerja keras, dan kemauan untuk belajar, saya percaya saya dapat mencapai tujuan yang saya ingginkan.
